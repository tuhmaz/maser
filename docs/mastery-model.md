# نظام إتقان المهارات ودفتر الأخطاء

## دفتر الأخطاء

### الفكرة
كل خطأ مهم يتحول إلى عنصر مراجعة.

### البيانات المحفوظة لكل خطأ
السؤال، إجابة الطالب، الإجابة الصحيحة، المهارة، سبب الخطأ (إن أمكن)، عدد مرات الخطأ، آخر محاولة، موعد المراجعة التالية، حالة الإتقان.

### دورة المراجعة
```
خطأ جديد → مراجعة قريبة → مراجعة لاحقة → اختبار تثبيت → متقن
```

### قواعد الجدولة
- الخطأ المتكرر يعود أسرع
- الإجابة الصحيحة مرة واحدة لا تعني الإتقان
- تُباعَد المراجعة بعد نجاحات متتالية (نمط تكرار متباعد Spaced Repetition)
- يمكن تقديم سؤال مشابه بدلًا من نفس السؤال بالضبط
- **لا يُغرق الطالب بعشرات الأخطاء في جلسة واحدة**

### واجهة دفتر الأخطاء
أخطاء اليوم، أخطاء تحتاج مراجعة، أخطاء متكررة، مهارات ضعيفة، أسئلة تم إتقانها، نسبة التحسن.

## نظام إتقان المهارات

### مؤشرات محفوظة لكل مهارة/طالب
عدد الأسئلة، الإجابات الصحيحة، الإجابات الخاطئة، الإجابات الحديثة، زمن الحل، مستوى صعوبة الأسئلة، نتائج المراجعة، عدد الأيام منذ آخر تدريب.

### حالات المهارة
```
not_started → introduced → practicing → developing → mastered
                                                     ↘ needs_review
```

### مبدأ الحساب

**لا يعتمد إتقان المهارة على سؤال واحد.** يجب مراعاة: عدد المحاولات، حداثة الإجابات، تنوع الأسئلة، صعوبة الأسئلة، نجاح الطالب بعد المراجعة، تكرار الخطأ.

### شرط القبول

يجب أن يستطيع النظام تفسير سبب التصنيف بجملة واضحة، مثال:

> "تحتاج إلى مراجعة هذه المهارة لأنك أخطأت في 3 من آخر 5 أسئلة."

لا يكفي عرض رقم غامض دون تفسير.

---

## الاختبار التشخيصي (خط الأساس)

**الهدف:** إنشاء خط أساس لمستوى الطالب قبل بدء أي خطة.

**طريقة البناء:** أسئلة موزعة على المهارات الأساسية، عدد محدود حتى لا ينسحب الطالب، صعوبة متدرجة، لا يُخبَر الطالب بأنه "فشل"، وتُعرض نتيجة مفهومة لا تعتمد على النسبة المئوية فقط.

**التقدير:** متقن / جيد / يحتاج مراجعة / يحتاج تأسيس

**المخرجات:** مستوى كل مهارة، نقاط القوة، نقاط الضعف، أول خطة يومية، الدرس المقترح للبدء، قائمة مهارات تحتاج تأسيسًا.

**شرط القبول:** بعد إكمال الاختبار يعرف النظام: أول درس مناسب، أول مهارة مراجعة، أول مجموعة أسئلة يومية، مستوى الطالب الأولي.
