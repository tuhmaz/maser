# نموذج السؤال ودورة حياة المحتوى

## دورة حياة المحتوى

```
Draft → In Review → Changes Requested → Approved → Published → Archived
```

## بيانات السؤال

الصف، المادة، الوحدة، الدرس، المهارة، الهدف التعليمي، نص السؤال، نوع السؤال، الخيارات، الإجابة الصحيحة، تفسير الحل، سبب خطأ كل خيار (عند الحاجة)، الصعوبة، الزمن المتوقع، مصدر المحتوى الداخلي، حالة المراجعة.

## أنواع الأسئلة (النسخة الأولى)

- اختيار من متعدد
- صح أو خطأ
- إدخال رقم
- اختيار أكثر من إجابة عند الضرورة
- ترتيب خطوات
- مطابقة بسيطة

## أنواع مؤجلة

رسم حر، إجابات مقالية طويلة، تصحيح تلقائي للنصوص المفتوحة، مسائل تعتمد على رفع صور، محادثات صوتية.

## قواعد جودة السؤال

- صياغة واضحة
- إجابة واحدة صحيحة عند الاختيار المفرد
- عدم وجود تلميح لغوي يكشف الحل
- الخيارات الخاطئة منطقية (لا عشوائية)
- تفسير الإجابة مفهوم
- ارتباط السؤال بمهارة محددة (لا يوجد سؤال بلا مهارة)
- تجنب التكرار السطحي
- مراجعة تربوية إلزامية قبل النشر

## قاعدة عدم كسر السجل التاريخي

**لا يُعدَّل السؤال المنشور بطريقة تُغيّر نتائج قديمة.** أي تعديل جوهري ينشئ `question_versions` جديدًا. تُحفظ نسخة السؤال كما ظهرت داخل `attempt_answers` حتى تبقى النتيجة القديمة قابلة للمراجعة بدقة، حتى لو تغيّر السؤال لاحقًا.

## استخدام الذكاء الاصطناعي في إنتاج المحتوى (اختياري، غير إلزامي في MVP)

**استخدامات مناسبة:** اقتراح صياغات أولية، اقتراح خيارات خاطئة منطقية، تصنيف الأسئلة حسب المهارة، اكتشاف التشابه/التكرار، اقتراح شرح بديل.

**لا يُنشر تلقائيًا أبدًا:** سؤال مولّد دون مراجعة بشرية، إجابة رياضية غير متحقَّقة، تفسير غير مراجَع.

**دورة المحتوى المدعوم بالذكاء الاصطناعي:**
```
توليد أولي → تحقق آلي → مراجعة بشرية → تجربة داخلية → اعتماد → نشر
```
