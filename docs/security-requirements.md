# متطلبات الأمان

## المتطلبات الأساسية

- HTTPS فقط في كل البيئات غير المحلية
- Cookies آمنة (`Secure`, `SameSite`)، `HttpOnly` عند الحاجة
- حماية CSRF حسب طريقة المصادقة المعتمدة
- تحديد محاولات تسجيل الدخول (rate limiting + lockout مؤقت)
- تشفير الأسرار (كلمات المرور عبر bcrypt/argon2، لا نص مباشر أبدًا)
- صلاحيات دقيقة (RBAC) على مستوى كل مسار API
- تحقق (validation) من كل مدخلات المستخدم في الخادم
- سجل تدقيق (`audit_logs`) لعمليات الإدارة الحساسة
- نسخ احتياطي دوري + اختبار استعادة فعلي
- تحديثات أمنية دورية للتبعيات
- فصل بيئة الإدارة (شبكيًا/منطقيًا) عن الواجهة العامة
- عدم كشف واجهات الإدارة العامة دون حماية (مصادقة + صلاحية قبل أي استجابة)
- رؤوس أمنية مناسبة (`Content-Security-Policy`, `X-Frame-Options`, `X-Content-Type-Options`, ...)
- سياسة رفع ملفات صارمة (نوع، حجم، فحص محتوى)

## القاعدة الرئيسية

> لا تثق بالواجهة الأمامية. كل صلاحية، نتيجة، اشتراك، أو تقدّم يجب التحقق منه داخل الخادم.

## اختبارات الأمان الإلزامية قبل أي نشر

- تجاوز الصلاحيات (privilege escalation)
- الوصول إلى بيانات طالب آخر (IDOR)
- تعديل نتيجة المحاولة من الواجهة
- إرسال إجابة بعد إنهاء الاختبار
- تخمين معرفات الموارد (لذلك تُستخدم UUID غير متسلسلة)
- رفع ملفات غير مسموحة
- محاولات تسجيل دخول متكررة
- التلاعب بالكوكيز والرموز (JWT tampering)

## الخصوصية

- جمع الحد الأدنى من البيانات
- عدم طلب معلومات غير لازمة للتعلم
- عدم إظهار بيانات الطلاب علنًا
- عدم استخدام الاسم الكامل في أي ترتيبات عامة مستقبلية
- توفير إعدادات إخفاء الملف الشخصي
- مراجعة قانونية قبل إطلاق حسابات الأطفال للعامة (COPPA-like considerations)
- توثيق الاحتفاظ بالبيانات وحذفها
- فصل بيانات المصادقة عن بيانات التقدم قدر الإمكان

## خصوصية التحليلات

- عدم إرسال نص السؤال الكامل إلى أدوات تحليل خارجية دون حاجة
- عدم إرسال بيانات حساسة إلى أطراف ثالثة
- استخدام معرفات تحليل غير مباشرة (pseudonymous IDs)
- احترام إعدادات الموافقة (consent)
- سياسة واضحة للاحتفاظ بالبيانات

## شرط قبول الجلسات

- الجلسة ثابتة بعد إعادة تحميل الصفحة
- لا يظهر الطالب "مسجّل دخول" أحيانًا و"خارج الحساب" أحيانًا أخرى بشكل عشوائي
- لا تُخزَّن كلمات المرور كنص مباشر أبدًا
- تُلغى الجلسات عند تغيير كلمة المرور
- يُمنع الوصول إلى صفحات الإدارة دون صلاحية صريحة
