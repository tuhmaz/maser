# وثيقة متطلبات المنتج (PRD) — Alemedu

## 1. تعريف المنتج

Alemedu ليست مكتبة دروس وليست منصة فيديوهات. المنتج الأساسي هو:

> منصة تحدد مستوى الطالب، وتخبره بما يجب أن يدرسه اليوم، وتختبره، وتحفظ أخطاءه، ثم تعيد تدريبه عليها حتى يتقن المهارة.

## 2. المشكلة

الطالب غالبًا يواجه واحدة أو أكثر مما يلي:

- لا يعرف من أين يبدأ
- يقرأ الدرس دون التأكد من فهمه
- يحل أسئلة كثيرة دون تحليل أخطائه
- يكرر دراسة المواضيع التي يعرفها
- ينسى المهارات القديمة
- لا يملك خطة يومية واضحة
- لا يستطيع ولي الأمر معرفة مستوى الطالب الحقيقي

## 3. الحل

بعد تسجيل الطالب:

1. يحدد الصف والفصل والمواد
2. ينفذ اختبارًا تشخيصيًا
3. يحصل على خريطة مهارات
4. تظهر له مهمة يومية
5. تُحفظ أخطاؤه تلقائيًا
6. يعاد اختباره في الأخطاء في أوقات مناسبة
7. تظهر له تقارير تقدم واضحة
8. يستطيع ولي الأمر متابعة الأداء عند تفعيل الربط

## 4. الفئات المستهدفة

| الفئة | الوصف |
|---|---|
| الطالب | من الصف الخامس حتى الثاني عشر |
| ولي الأمر | يتابع تقدم الأبناء دون تفاصيل تعليمية غير ضرورية |
| مدير المحتوى | ينشئ الصفوف/المواد/الوحدات/الدروس/المهارات/الأسئلة |
| المراجع التعليمي | يراجع دقة السؤال والحل والتفسير قبل النشر |
| مدير النظام | يدير المستخدمين والصلاحيات والإعدادات |
| المعلم | يضاف لاحقًا لإنشاء الصفوف والواجبات والاختبارات |

## 5. تقسيم المنتج حسب المرحلة العمرية

- **الصف 5–7:** واجهة بسيطة، نصوص قصيرة، صور توضيحية، مكافآت واضحة، اختبارات قصيرة، إشراف اختياري لولي الأمر.
- **الصف 8–10:** تركيز على تأسيس المهارات، كشف الفجوات القديمة، اختبارات وحدات، خطط مراجعة.
- **الصف 11–12:** خطط دراسية طويلة/قصيرة، محاكاة امتحانات، تصنيف الأسئلة حسب الصعوبة، دفتر أخطاء متقدم.

## 6. نطاق النسخة التجريبية الأولى (MVP)

**مثبّت ولا يتغير أثناء البرمجة:**

- الدولة: الأردن
- الصف: السابع
- المادة: الرياضيات
- الفصل: فصل دراسي واحد
- الاستخدام: مجاني تجريبي

**سبب الاختيار:** الرياضيات مناسبة جدًا لتحليل المهارات، قابلة للتقسيم إلى مهارات دقيقة، تقاس الإجابات الصحيحة/الخاطئة بوضوح، ويمكن اختبار الفكرة دون ضغط موسمي (مثل التوجيهي).

### ما يدخل في MVP
إنشاء حساب/دخول، اختيار الصف، عرض المادة والوحدات، عرض الدروس والمهارات، الاختبار التشخيصي، اختبارات الدروس والوحدات، حفظ المحاولات، تحليل الإجابات، دفتر الأخطاء، جدولة المراجعة، المهمة اليومية، التقدم العام، سلسلة الأيام، لوحة إدارة الأسئلة، تقارير تشغيل أساسية، ربط إعلاني مع موقع الإيمان.

### ما يؤجَّل
تطبيق Android/iOS، الدفع والاشتراكات، الصفوف الافتراضية، لوحة المعلم، محادثة ذكاء اصطناعي مفتوحة، الدروس بالفيديو، المنافسات العامة، الترتيب الوطني، الشهادات، تسجيل الدخول الموحد مع موقع الإيمان، بقية الصفوف/المواد، الإشعارات المتقدمة، المحتوى الذي ينشئه المستخدمون.

## 7. مؤشرات نجاح المنتج

لا يُقاس النجاح بعدد الحسابات فقط:

- **التسجيل:** نسبة إكمال التسجيل، نسبة اختيار الصف/المادة، نسبة بدء الاختبار التشخيصي
- **التفاعل:** نسبة إكمال أول اختبار، متوسط الأسئلة/الجلسة، متوسط الوقت داخل المنصة، عدد الدروس المبدوءة، عدد المهام المكتملة
- **العودة:** العودة في اليوم التالي، العودة خلال أسبوع، عدد الأيام المتواصلة
- **التعلم:** تحسن النتيجة بعد المراجعة، انخفاض تكرار الخطأ، عدد المهارات المتقنة
- **جودة المحتوى:** نسبة الإبلاغ عن مشاكل الأسئلة، نسبة الخطأ غير الطبيعية، الأسئلة المتروكة، الاختبارات غير المكتملة

راجع [`analytics-events.md`](analytics-events.md) للأحداث التي تغذي هذه المؤشرات.

## 8. المخاطر الرئيسية

| الخطر | الحل |
|---|---|
| تضخم المشروع | تثبيت نطاق MVP ومنع إضافة وظائف دون قرار واضح |
| ضعف المحتوى | مراجعة بشرية + دورة نشر رسمية |
| منصة جميلة دون عودة طلاب | قياس العودة والمهمة اليومية منذ البداية |
| أخطاء الجلسات | اختبارات تلقائية للمصادقة/الجلسة أولًا |
| خلط Alemedu مع موقع الإيمان | قواعد بيانات وخدمات مستقلة بالكامل |
| ارتفاع تكلفة الذكاء الاصطناعي | ليس جزءًا إجباريًا من MVP |
| كثرة الصفوف والمواد | التوسع صفًا/مادة بعد إثبات الاستخدام |
| فقدان البيانات | نسخ احتياطي + اختبار استعادة + مراقبة |
| ضعف تجربة الهاتف | تصميم Mobile First + اختبار أجهزة حقيقية |

## 9. خطة التوسع بعد نجاح MVP

1. إكمال مادة الرياضيات للصف المختار
2. إضافة صف قريب (نفس بنية المادة)
3. إضافة مادة قابلة للقياس (مثل العلوم)
4. إضافة الصفوف الأعلى
5. إضافة التوجيهي بعد إثبات جودة نظام الأسئلة
6. إضافة ولي الأمر
7. إضافة المعلم والمدرسة
8. إضافة الاشتراكات
9. تطبيق الهاتف والإشعارات

## 10. بوابة القرار بعد التجربة

| القرار | الشرط |
|---|---|
| الاستمرار | عاد الطلاب واستخدموا المهام ودفتر الأخطاء |
| التعديل | سجّل الطلاب لكن لم يكملوا الاختبارات |
| تغيير نطاق المحتوى | المشكلة في المادة/الصف وليس المنتج |
| الإيقاف المؤقت | لا توجد عودة أو قيمة تعليمية واضحة |
