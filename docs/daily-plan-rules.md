# قواعد المهمة اليومية ومحرك الاختبارات

## أنواع الاختبارات

| النوع | الوصف |
|---|---|
| اختبار تشخيصي | يحدد مستوى الطالب قبل بدء الخطة |
| اختبار درس | يقيس مهارات درس واحد |
| اختبار وحدة | يقيس عدة دروس مترابطة |
| مراجعة أخطاء | تعيد عرض أخطاء سابقة |
| مهمة يومية | تجمع شرحًا قصيرًا + أسئلة جديدة + أسئلة مراجعة |

## دورة تنفيذ الاختبار

```
إنشاء محاولة
  → تحديد الأسئلة
  → حفظ ترتيب الأسئلة
  → عرض السؤال
  → حفظ الإجابة فورًا
  → تسجيل الزمن
  → إكمال/إنهاء المحاولة
  → حساب النتيجة
  → تحديث المهارات
  → إنشاء أخطاء للمراجعة
  → توليد توصيات
  → عرض التقرير
```

## قواعد صارمة (أمان النتيجة)

- **لا تعتمد النتيجة على الواجهة.** الحساب النهائي يتم داخل الـ API فقط.
- تُحفظ الإجابات تدريجيًا (بعد كل سؤال، وليس عند الإرسال النهائي فقط)
- يستطيع الطالب العودة بعد انقطاع الاتصال (استئناف المحاولة)
- لا تُرسل الإجابة الصحيحة قبل تسليم السؤال
- يُمنع تكرار إرسال نفس الإجابة بطريقة تُفسد النتيجة (idempotency على مستوى السؤال داخل المحاولة)
- يُسجَّل وقت بداية ونهاية المحاولة

## المهمة اليومية

### المكونات
1. مراجعة قصيرة
2. شرح أو تذكير
3. أسئلة جديدة
4. سؤال من دفتر الأخطاء
5. اختبار تثبيت

### مدخلات توليد المهمة
مستوى الطالب، الصف، المادة، الدرس الحالي، المهارات الضعيفة، الأخطاء المجدولة، الوقت المتاح، المهام غير المكتملة.

### أنواع الخطط
خطة قصيرة، خطة عادية، خطة مراجعة، خطة تعويض بعد الغياب.

### قواعد مهمة
- لا تتجاوز المهمة قدرة الطالب
- تظهر مدة تقريبية
- يمكن إكمالها على أجزاء
- لا تُضيَّع النتيجة بعد الخروج
- لا تعتمد على أسئلة عشوائية فقط
- تحتوي على هدف واضح

## لوحة تقدم الطالب

### العناصر
نسبة إكمال المادة، عدد المهارات المتقنة، المهارات التي تحتاج مراجعة، نتيجة آخر اختبار، سلسلة الأيام، عدد الأسئلة المحلولة، تحسن آخر أسبوع، المهمة التالية، موعد المراجعة القادمة.

### ما يجب تجنبه
رسوم كثيرة دون معنى، أرقام لا يفهمها الطالب، مقارنة مهينة مع الآخرين، رسائل سلبية، تضخيم الإنجاز دون تعلم حقيقي.

### أمثلة رسائل مقبولة
- "أصبحت أفضل في مقارنة الأعداد النسبية."
- "لديك مهارتان تحتاجان إلى مراجعة قصيرة."
- "أكمل ثلاثة أسئلة إضافية لتثبيت هذه المهارة."

---

## نظام الإنجازات

**إنجازات مناسبة:** إكمال أول اختبار، إكمال أول مهمة، مراجعة أول خطأ، إتقان أول مهارة، الدراسة لعدة أيام متواصلة، تحسين نتيجة مهارة، العودة بعد انقطاع.

**قواعد:** الإنجازات لا تعوّض التعلم، لا تُمنح نقاط على النقر فقط، لا تشجّع الحل السريع العشوائي، **لا مسابقات عامة في النسخة الأولى**، يمكن تعطيل المؤثرات البصرية من الإعدادات.
