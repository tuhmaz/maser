# هيكل المنهاج

## التسلسل الهرمي

```
المرحلة الدراسية
  → الصف
    → السنة الدراسية
      → الفصل
        → المادة
          → الوحدة
            → الدرس
              → المهارة
                → الهدف التعليمي
                  → السؤال
```

## مثال (نطاق النسخة الأولى)

```
الصف السابع
└── الرياضيات
    └── الوحدة الأولى
        └── درس الأعداد النسبية
            ├── مقارنة الأعداد النسبية
            ├── ترتيب الأعداد النسبية
            └── تمثيل الأعداد على خط الأعداد
```

## بيانات كل مهارة

- اسم المهارة
- وصف قصير
- المتطلبات السابقة (prerequisites)
- مستوى الصعوبة
- نواتج التعلم
- أنواع الأسئلة المناسبة
- عدد الأسئلة المطلوب
- المهارات اللاحقة المرتبطة بها

## شرط الانتقال لمرحلة تصميم قاعدة البيانات

لا يبدأ تصميم قاعدة البيانات قبل اعتماد: الصف، المادة، هيكل المنهاج، أنواع الأسئلة، طريقة حساب التقدم، صلاحيات المستخدمين.

## المخرجات المطلوبة

- ملف كامل لهيكل المادة (الصف السابع / الرياضيات / الفصل الأول)
- قائمة المهارات
- مصفوفة ارتباط الدروس بالمهارات (`lesson_skills`)
- مصفوفة المتطلبات السابقة (`skill_prerequisites`)
- خطة إنتاج الأسئلة

راجع [`database-design.md`](database-design.md) لتفاصيل الجداول المطابقة لهذا الهيكل.
