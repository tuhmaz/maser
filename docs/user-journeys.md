## رحلة الطالب الأولى (Golden Path)

1. فتح الصفحة الرئيسية
2. الضغط على "ابدأ مجانًا"
3. إنشاء الحساب
4. اختيار الصف
5. اختيار الفصل
6. اختيار المادة
7. تنفيذ اختبار تشخيصي
8. مشاهدة تقرير أولي
9. إنشاء أول مهمة يومية
10. فتح لوحة التحكم

## قواعد التصميم

- أقل عدد ممكن من الخطوات
- الأزرار الرئيسية واضحة
- عدم عرض عشرات الخيارات في صفحة واحدة
- اللغة العربية المبسطة، تجنب الجداول المعقدة للطالب
- عرض التقدم بصريًا دون رسوم ثقيلة بلا فائدة
- تصميم شاشات الهاتف أولًا
- إمكانية الاستخدام بلوحة المفاتيح

## المخرجات المطلوبة من تصميم UX

خريطة تنقل، Wireframes، تصميم الواجهات الرئيسية، مكتبة مكونات، حالات التحميل/الخطأ/الفراغ، نسخ الهاتف والكمبيوتر.

## لوحة الإدارة (admin.alemedu.com)

### الأقسام

Dashboard, Curriculum, Grades, Subjects, Units, Lessons, Skills, Questions, Quizzes, Reviews, Students, Reports, Content Issues, Audit Logs, Settings

### الأدوار والصلاحيات

| الدور | الصلاحية |
|---|---|
| محرر المحتوى | ينشئ ويعدل المسودات |
| المراجع | يوافق أو يطلب تعديلات |
| الناشر | ينشر النسخة المعتمدة |
| الدعم | يشاهد بيانات محدودة لمعالجة المشاكل |
| المدير | يدير إعدادات المنصة |

### الوظائف

إنشاء/تعديل المنهاج، استيراد الأسئلة، مراجعة الأسئلة، نشر/أرشفة المحتوى، البحث والتصفية، اكتشاف الأسئلة المكررة، عرض أداء السؤال (نسبة الخطأ، عدد الاستخدام)، تعطيل سؤال دون حذف النتائج السابقة، إدارة الصلاحيات، سجل التغييرات.
